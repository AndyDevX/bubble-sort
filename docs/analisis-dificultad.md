# Análisis de dificultad

Generado con `npm run analizar` (niveles 1–80, 20 niveles por número, 8 partidas
de jugador casual por nivel; semilla fija). No editar a mano: vuelve a ejecutar el script.

## Resumen

- **Resolubles sin habilidades**: 1600/1600 (100 %). Con lluvia, `npm run simular`.
- **Tendencia**: correlación de Spearman nivel ↔ índice **ρ = 0,53** (1 = sube siempre);
  nivel ↔ éxito del jugador casual ρ = -0,55 (negativa = cada vez gana menos).
- **Retrocesos** (el índice baja más de 5 puntos respecto al nivel anterior): 56, 76.
- **Mesetas** (tramos de 10 niveles con pendiente casi nula): 31–40, 41–50, 51–60, 61–70, 71–80.

Índice = 25 % movimientos de la solución + 15 % esfuerzo de búsqueda + 30 % fracaso del jugador
casual + 15 % niebla + 15 % ritmo de la lluvia (cada medida normalizada entre el mínimo y el máximo
de los niveles analizados).
